# Arşivlenmiş sürümler

İlk herkese açık yayının önceki sürüm arşivi yoktur. Güncel sürüm [üstteki skill klasöründe](../README.md) bulunur.

Sonraki güncellemeden önce iki dildeki önceki commit'li sürümleri deponun [sürüm yönetimi talimatlarına](../../CONTRIBUTING.md) göre arşivleyin. Arşivler `vMAJOR.MINOR.PATCH.zip` biçiminde adlandırılır; kaynak commit'i ve dosya hash'lerini içeren `ARCHIVE-MANIFEST.json` bulunur. Arşiv aracı, arşiv klasörünü paketin dışında bırakır.

Yayımlanmış ZIP'leri bayt düzeyinde koruyun. İncelemek için skill keşif dizinlerinin dışında açıp manifesti doğrulayın; arşivdeki SKILL.md dosyalarını aktif skill olarak kaydetmeyin.
