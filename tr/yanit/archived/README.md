# Arşivlenmiş sürümler

Bu ilk depo yayınıdır; arşivlenecek önceki yayımlanmış sürüm yoktur. [Güncel paket](../README.md) bir üst klasörde bulunur.

Gelecekte sürüm değiştirmeden önce iki dil paketinin commit'li sürümünü deponun [sürüm yönetimi adımlarıyla](../../CONTRIBUTING.md) arşivleyin. Yayımlanmış ZIP'leri değiştirmeyin; eski bir sürümü yalnızca aktif skill keşif dizinlerinin dışında açın.
