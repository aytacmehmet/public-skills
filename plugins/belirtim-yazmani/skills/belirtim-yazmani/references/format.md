# Data format

- **R-BYW-FMT-01** Private TOON keeps the authoritative delivery.spec and private control separate. Public schema is ../../../schema/handoff.schema.json, urn:specification:3.0:handoff. The manifest role specification names the prefixed TOON authority; roles also name schema, readiness, decisions, architecture, references and optional Excel/delta. No fixed fsts filename or duplicate JSON authority is emitted. Read 2.0.x only as baseline/import. TOON 4.1 strict, UTF-8/LF, two-space indent and comma delimiter apply; quote IDs and exact decimals.
- **R-BYW-FMT-02** Unknown business values, contradictions and missing required context block delivery. Only bounded developer implementation records may be OPEN: explicit ownership/domain, supplied context, fixed constraints and local reference IDs; no functional contract change. Readiness reports DELIVERABLE separately from READY_FOR_DEVELOPER_DECISIONS or READY_FOR_CODING. Each referenced text/list pointer resolves on decoded local TOON; hashes bind exact bytes. [] means known empty, not omitted facts.
- **R-BYW-FMT-03** Every basename starts with the approved unique short name, including PNGs and supplemental contracts. Manifest inventory includes itself with an external self-hash exception; other hashes are exact. Baseline content, dependency contracts and necessary source excerpts are locally included. External citations can be retained as provenance only when the complete needed development information is already included; they are never required to obtain missing context. Excel/objects/readme are projections; PNG is layout authority only. No code, local tool references, host-dependent commands or developer model selection.
