Automatic invocation is enabled. In Claude Code, use `/yula:sap-released-object-developer` when explicit invocation is preferred. In Codex, select the Yula skill in the skill picker.

Answers follow the user's language. Technical identifiers stay unchanged. The model-facing rules are English and load detailed references only when needed.
