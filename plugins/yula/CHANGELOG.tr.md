# Değişiklik geçmişi

[English](CHANGELOG.md) · Türkçe

## 1.4.1 — 2026-10-01

- Birleşmiş Yula 1.4.0 kaynak yayını temelinde ilk public-skills plugin dağıtımı; kaynak sürümünün devamlılığı korunur.
- Tam plugin iki native marketplace'te `yula@aytacmehmet-public` adıyla yayımlanır; İngilizce/Türkçe kurulum yönergeleri ve harici ZIP üreticisi güncellenir.
- Runtime sorgu davranışı, sıkıştırılmış veritabanı, kaynak lisansları ve tarihsel yeterlilik raporları korunur. Runtime, host ve skill sürüm bilgileri 1.4.1 olarak eşitlenir.
- Paket hash'leri, marketplace, sürüm geçmişi ve runtime kontrolleri mevcut public repo doğrulama iş akışına eklenir.
- Teslim dosyaları büyük/küçük harfe duyarlı göreli POSIX adlarıyla sıralanır; Windows ve Linux manifest sırası eşitlenir. Gerçek teslim üretimiyle regresyon testi eklendi.

Önceki kaynak yayınları [upstream kaydında](PUBLICATION.json), [kaynak/arayüz açıklamasında](references/provenance.tr.md) ve sürümlü test raporlarında tanımlıdır. Daha önce public-skills'te plugin yayını veya arşivi bulunduğu iddia edilmez. Sonraki yayınlarda eski sürümler commit'li Git geçmişinden alınır; teslim ZIP'leri harici çıktılardır.
